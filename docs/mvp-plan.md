# EnviroSense AI MVP Plan

## Confirmed Scope

- Region: Sindh
- Priority areas: Hyderabad, Karachi, Sukkur, Larkana, Dadu, Thatta, Badin
- Language: English first
- Users: NGO admin, field workers, and anonymous public reporters
- Alerts: Web first, email and WhatsApp later
- Hosting target: free tier first

## MVP Modules

1. Admin dashboard
2. Flood risk map and district list
3. Water quality lab-value assessment
4. Public report submission
5. Report status change by admin
6. Web alert publishing
7. Supabase auth, database, and storage integration

## Recommended Free Stack

- Vercel Hobby for hosting
- Supabase Free for auth, PostgreSQL, and media storage
- Open-Meteo for rainfall and precipitation forecast
- OpenStreetMap/Leaflet for map interactions

## Phase 2

- Email alerts
- WhatsApp alerts
- Sensor ingestion
- Safe water points
- Relief location tracking
- PDF reports
